# CLI Reference

The Bash CLI is a local protocol installer and validator. At reviewed commit
`089baa2`, it reports `Cyberpunk CLI v0.4.0`; this documentation remains
forthcoming until a matching public semantic tag exists. It never launches
model processes or claims provider-session capability.

Recommended path: [init](./init.md) -> [validate](./validate.md) ->
[status](./status.md), then use [generated project structure](./generated-project-structure.md)
to inspect what changed.
