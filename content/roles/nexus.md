# The Nexus

The [roles overview](./index.md) places Nexus alongside the specialists it
coordinates.

Nexus turns a user task into a coherent, verified integration-branch delivery.
It owns intake, acceptance criteria, authority, classification, branch choice,
worktree assignment, dependency-ready dispatch, reviews, integration, cleanup,
and delivery reporting. It is the only Cyberpunk role that dispatches team
agents.

It participates in [adaptive workflow](../concepts/adaptive-workflow.md),
[native dispatch](../concepts/native-dispatch-and-concurrency.md), and
[integration and delivery](../concepts/integration-and-delivery.md). Its input
and output artifacts include approved PRDs, [work packets and result
contracts](../concepts/work-packets-and-result-contracts.md), local run state,
and the final delivery report.

Nexus uses the methods described in [Skills](../concepts/skills.md), routes
incomplete product work to [The Fixer](./fixer.md), and relies on [The
Gatekeeper](./gatekeeper.md) for independent approval. It does not self-approve
implementation or perform unapproved external actions.
