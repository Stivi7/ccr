# The Neon

Neon owns user-facing behavior in an assigned scope: semantics, keyboard flow,
client state, visual consistency, responsive layouts, and browser-facing
performance. It verifies relevant loading, empty, error, success, keyboard,
and viewport states without inventing backend behavior.

Neon implements a [work packet](../concepts/work-packets-and-result-contracts.md)
inside [branch and worktree isolation](../concepts/branches-and-worktrees.md).
Its output is a scoped commit and accessibility evidence, using quality methods
from [Skills](../concepts/skills.md).

It works adjacent to [The Coder](./coder.md) and [The Daemon](./daemon.md) when
Mind has defined a shared contract. [The Gatekeeper](./gatekeeper.md) performs
the next independent review.
