# Roles

Roles create clear ownership while sharing the same evidence and authority
rules. Nexus coordinates the full lifecycle; other roles stay within their
assigned responsibility and do not dispatch sibling or nested team agents.

Recommended path: [Nexus](./nexus.md) -> [Fixer](./fixer.md) -> [Operator](./operator.md)
-> [Mind](./mind.md) -> [Fragmenter](./fragmenter.md) -> [Coder](./coder.md)
-> [Gatekeeper](./gatekeeper.md).
