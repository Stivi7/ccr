# Adaptive workflow and task classification

Nexus chooses the smallest safe workflow rather than applying the same ceremony
to every task. A quick task is localized, reversible, familiar, and low risk.
A standard task has a meaningful behavior change, multiple files, or moderate
uncertainty. A complex task crosses architecture, security, migration,
operations, or high uncertainty.

The [Nexus](../roles/nexus.md) records objective, authority, acceptance, and
the selected route. A materially incomplete product request goes first to
[requirements discovery](./requirements-discovery.md); an approved complex
plan then becomes ownership-safe [work packets](./work-packets-and-result-contracts.md).

[Configuration](../cli/configuration.md) expresses policy such as
`parallelism` and the maximum agent limit, but observed runtime capability
belongs in [project memory and run state](./project-memory-and-run-state.md).
The next stage is either discovery, planning, or the appropriate specialist
assignment.
