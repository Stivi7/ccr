# Contributing

This cluster helps contributors change curated documentation without blurring
its source boundaries. The site is maintained manually from canonical protocol
and CLI evidence; it is not an automated mirror of the CLI repository.

Recommended path: [Development setup](./development-setup.md) -> [Test and
verification commands](./verification.md) -> [Documentation contribution
conventions](./documentation-conventions.md).

- [Development setup](./development-setup.md)
- [Test and verification commands](./verification.md)
- [Documentation contribution conventions](./documentation-conventions.md)

Read [manual tagged release](../guides/manual-tagged-release.md) before changing
release-sensitive prose, and [project memory and run state](../concepts/project-memory-and-run-state.md)
for the difference between durable evidence and local execution history.
