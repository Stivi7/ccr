# Cyberpunk Context Runners

Cyberpunk Context Runners is a runtime-neutral engineering-team protocol for
planning, implementing, reviewing, and delivering changes with coding agents.
Its Bash CLI installs and validates the protocol; it does not launch model
processes or manage provider sessions.
