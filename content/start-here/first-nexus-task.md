# First Nexus task

Start your chosen coding-agent runtime normally, then ask **The Nexus** to
take a clear task. The CLI does not launch that runtime; it installs and
validates the policy the runtime reads.

```text
Act as The Nexus. Add account recovery with expiring, single-use tokens.
Deliver the verified integration branch; do not push or open a pull request.
```

Nexus sets the objective, acceptance criteria, authority, branch, and workflow
depth. It routes materially incomplete product ideas to [The Fixer](../roles/fixer.md)
before planning, and assigns isolated work packets only after the work is
understood. Learn the full responsibility on [The Nexus](../roles/nexus.md)
and the choices on [adaptive workflow](../concepts/adaptive-workflow.md).

For a new product or architectural idea, ask The Fixer to help define it
before implementation. Then trace the resulting [work packet and result
contract](../concepts/work-packets-and-result-contracts.md) through review and
delivery.
